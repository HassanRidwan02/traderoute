# 🌍 TradeRoute — Africa's B2B Procurement Network

A buyer-first reverse marketplace where businesses post procurement requests and vendors compete with bids. Built for Nigerian and African SME markets.

## 🚀 Quick Start

```bash
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000)

## 📦 Build for Production

```bash
npm run build
```

## 🏗️ Project Structure

```
src/
├── data/store.js          # localStorage data layer + seed data
├── components/
│   ├── Navbar.jsx         # Sticky nav with ticker
│   └── RequestCard.jsx    # Reusable request card
└── pages/
    ├── Home.jsx           # Landing page with hero + stats
    ├── Board.jsx          # Browse & filter all requests
    ├── RequestDetail.jsx  # Request + bid submission
    ├── PostRequest.jsx    # 3-step post form
    └── Dashboard.jsx      # Buyer/vendor dashboard
```

## ✨ Features

- **Buyer Board** — Post procurement requests in 3 steps
- **Vendor Board** — Browse and filter open requests
- **Bid System** — Vendors submit offers with pricing and pitch
- **Dashboard** — Track your requests and bids
- **Seed Data** — 5 realistic Nigerian market requests pre-loaded
- **localStorage** — Fully functional offline, no backend needed
- **Responsive** — Works on mobile and desktop

## 🎨 Design

- Dark earthy palette inspired by African trade markets
- Syne + DM Sans typography
- Animated cards, ticker, gradient hero
- Category-colored badges and filters

## 🏆 Competition Categories

Fits: **E-commerce**, **SaaS**, **Logistics / Transportation**

## 📝 How to Demo

1. Open the board — 5 seed requests are pre-loaded
2. Click any request → submit a vendor bid
3. Post a new request → fill the 3-step form
4. Dashboard → enter any name + phone to see your activity

No signup, no backend, no Firebase needed.
